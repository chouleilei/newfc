## 固定方向

**以 newbd 的固定源码快照为基础，在 newfc 独立仓库内扩展 lishui-finance-ai 的业务功能。** 原项目各自运行，代码、运行数据和部署均独立。采用 TypeScript + Express + SQLite、本地文件、应用内 AI 和 systemd；不引入 Dify/DB-GPT。

## 状态与追踪

- **已确定**：用户确认的项目方向、名称、隔离和技术目标。
- **设计基线**：目前建议采用的接口与实现约束，仍需代码和样本证明可行。
- **待定 OPEN-xx**：未决的具体事项、截止阶段和影响，统一维护在实施任务中。
- **已实现/已验证**：必须附新仓库提交及实际验证证据。目前所有功能均尚未在 newfc 实现或验证。

功能 ID 沿用 lishui 来源清单；AC-Fxx 对应功能验收，AC-Xxx 对应跨域验收，T-x 为阶段任务。开发记录至少标明相关功能、任务、验收 ID 和实际差异。来源测试只是场景参考，不是 newfc 的测试通过记录。

维护已有 7 个主题即可；不预建大量空目录、每页模板或平台化流程。初始化源码时保留本目录，按需补充领域细设计。任意缩小已确定的业务范围须显式记录，不能把暂未完成标成不需要。
