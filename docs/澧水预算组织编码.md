## 编码规则

- 层级式数字码,每级 2 位:`01` → `0101` → `010101`;
- `sort_order` 取编码数值,树展示与列表顺序天然一致;
- **只有叶子组织可以录数**(矩阵列 = 叶子组织);汇总节点(澧水集团/澧水本级/澧能公司/全州优能/泽通公司/机电公司)的值由子树自动汇总。
