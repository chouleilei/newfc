# newfc 仓库独立化清理（2026-10-02）

范围：T-0/T-7；AC-X01（运行隔离）、AC-F20（助手）、AC-F22（制度）。本轮按用户要求清理完整仓库中的非必要来源项目痕迹；运行数据、财务口径与历史证据均不因命名清理而重写。本轮未部署、未创建远程仓库、未推送或提交当前工作树，保留此前尚未提交的开发工作。

## 已完成的清理

- 移除 `backend/scripts/seed-lishui-org.cjs` 与 `seed-lishui-account.cjs`：它们将本地 newfc 数据库操作与旧服务 3748 API 混用，且包含清表或创建主数据流程。保留的组织/科目/指标定义提取为 `backend/scripts/fixtures/water-finance-master-data.cjs`，没有网络、数据库或执行入口；模拟 E2E 改用该纯夹具。
- 产品助手统一显示“财务助手”，空态组件改为 `FinanceEmpty`；CSS 类、CSS 变量、自定义事件和新写入的浏览器键统一使用 newfc 命名。同步更新消费者、主题、样式、页面能力目录与浏览器用例选择器，保留年度账册视觉风格。
- 浏览器兼容读取集中在 `frontend/src/utils/browserStorage.ts`。同源下迁移主题、表格配置、焦点/滚动位置与已按服务端 ID 隔离的账号偏好；新键优先，成功写入后才移除旧键，存储受限时保留旧值。旧显示名/default 偏好不迁入；历史助手入口标签更新，用户自行命名的视图不改。
- 制度样本改为 `deploy/expense-policy-v1.json`，标题统一为本项目业务名称；测试改为 `backend/tests/t6-expense-policy.test.ts`。现行操作手册、源码说明与规格链接跟随新路径。
- 修正助手接口文档中的旧端口，全部示例指向 3760。README、总计划和现行业务规范改按 newfc 自身描述；删除无必要的源项目对照注释和源项目设计选型历史。历史资源对比移入源码来源记录。
- E2E 默认使用独立前端 `.e2e-dist`，支持 `E2E_BACKEND_DIST` 选择后端隔离构建；拒绝旧服务 3748 与正式服务 3760 作为测试目标。新增源码/脚本地址回归检查，覆盖此前漏查的旧初始化脚本类别。
