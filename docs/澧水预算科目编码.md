# 澧水集团预算科目编码(完整适配 · 当前版)

> 依据用户预算模板六大 sheet(收入成本表/发电收入/非电收入/非电营业成本/管理类费用表/人工成本表)建成,
> 本项目保留科目与利润表口径；测试定义见 `backend/scripts/fixtures/water-finance-master-data.cjs`。旧 API 初始化脚本已移除；正式主数据通过页面维护或受控导入。
> **科目编码全局唯一且不可变**,预算/实际数 Excel 导入按"科目编码"匹配。

## 编码规则

- 类型前缀:`I`=income 收入 / `C`=cost 成本 / `E`=expense 费用 / `Q`=quantity 数量指标;
- 根节点 1 位序号(`I1`),其下每级 2 位(`I12` → `I1201` → …),最深 6 级(福利费-节日慰问-职工类别);
- `sort_order` 按模板出现顺序赋值,树展示顺序与模板一致;
- 与组织编码(`docs/澧水预算组织编码.md`)配合:当前预算矩阵基准 = 19 叶子组织 × 201 叶子科目;实际可见科目还会按组织-科目适用范围进一步过滤。

## 数量型科目(2026-08-22 V2 迁移新增,当前迁移版本 V14)

- **类型 quantity 为第四类科目**,与金额科目分树存放,同父类型必须一致;指标公式只能引用金额科目;
- 每个数量科目带**计量单位**(万度/元/度/%/人)与**汇总方式**:可加总(sum,如电量)沿组织/科目上级求和;不汇总(none,如电价/税率/平均人数)仅叶子录值;
- 存储:金额仍为整数分;数量按 **10^4 缩放整数**存储(最多四位小数),与金额完全隔离——数量行金额恒为 0,不参与任何金额汇总/指标/报表,反之亦然;
- 录入:预算编制与实际数维护矩阵中,数量列按列头单位原值录入(紫色边框);Excel 导入模板新增"数量/累计数量"列(金额/数量二选一,按科目类型校验);导出含"预算数量/数量单位"列;
- 树快照携带单位与汇总方式,锁定版本历史口径完整;单位与汇总方式创建后可修改(仅数量科目)。

## 利润及管理指标(P01~P07)与模板行布局

| 编码 | 指标 | 公式(科目值带利润方向符号) |
|---|---|---|
| P01 | 营业总收入 | +I1 |
| P02 | 营业总成本 | +C1+C3+C4+E1+E2+E3(**利润表口径,不含增值税**) |
| P03 | 营业利润 | +P01+P02+I2 |
| P04 | 利润总额 | +P05−C6（C6 为负数，即净利润加回所得税费用） |
| P05 | 净利润 | +P07+P06（总成本为负数，即总收入减总成本） |
| P06 | 总成本 | +P02+C5+C6（营业成本、税金及附加、销售/管理/财务费用、减值损失、营业外支出、所得税费用；**不含增值税 C2**） |
| P07 | 总收入 | +P01+I2+I3（营业总收入、投资收益、营业外收入） |

**利润表按模板「利润表」sheet 逐行展示(15 行,`frontend/src/utils/sheets.ts` 的 `PROFIT_ROWS`)**:

一、营业总收入(P01)/二、营业总成本(P02)/其中:营业成本(C1)、税金及附加(C3)、销售费用(E1)、管理费用(E2)、财务费用(E3)、资产减值损失(C4)/加:投资收益(I2)/三、营业利润(P03)/加:营业外收入(I3)/减:营业外支出(C5)/四、利润总额(P04)/减:所得税费用(C6)/五、净利润(P05)。

小计行为指标计算行,取数行为科目子树带符号汇总;全部只读、由明细表录入自动勾稽。**P06/P07 是管理口径，不新增法定利润表行**；模板"资产减值损失"行取自 C4「信用减值损失（处置损益）」。

**收入成本表(master)同样按模板展示 4 个计算行**(`SHEET_METRIC_ROWS`,V5 迁移同时对齐根科目顺序):
总收入(P07,表首)→ 营业收入/投资收益/营业外收入 → 总成本(P06)→ 营业成本/税金及附加/销售费用/管理费用/财务费用/信用减值/营业外支出/所得税费用（增值税 C2 不计入）→ 利润总额(P04)→ 减:所得税费用(C6)→ 净利润(P05)。
其余明细表的"合计/汇总"行即其根科目汇总行,无需另设计算行。

勾稽关系固定为：P05 净利润=P07 总收入−P06 总成本的业务展示额；P04 利润总额=P05 净利润+所得税费用的业务展示额。增值税不参与上述收入、成本和利润指标。

## 归一化口径(与模板差异,均已按主分类归位)

1. 各子公司清单中的 **营业外收入/营业外支出/政府补助/所得税/资产减值损失** 不留在"非电产业收入/成本"子树,归位到 I3/C5/I301/C6/C4——避免与利润表口径重复;
2. 模板"资产减值损失"并入主表"信用减值损失（处置损益）"(C4);
3. 管理类费用表 **"一~五"汇总类目不建节点**(模板未定义 1~26 项的归集口径,人工成本除外);"人工成本"子树按人工成本表全量展开,1~6 项(工资/工会/福利/劳保/社保/教育)只在此处建一次,不重复;
4. 发电收入/电量按电站的拆分是**组织维度**(江垭/皂市/澧能各项目),不建科目;澧能"管理服务费收入"下的倪家洞/六字界/天子山/磨子岭/白竹同理;
5. 机电公司充电桩收入的 5 个项目(福湘酒店等)无对应组织,建为 I1247 子科目;
6. 模板序号错乱已修正:人工成本表两个"五"(劳动保护费/社会保险费)、非电收入表重复序号(3/1.11/2.6 等)、非电营业成本"博弘物业"下 3 行空名称(未建,待模板补齐);
7. 模板用字差异保留原样:收入侧"灌装水"(I1239)、成本侧"罐装水"(C1219)。
