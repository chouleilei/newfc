# 独立项目排查（2026-10-02）

范围：产品品牌、业务导航、默认展开、金额单位、登录会话与个人偏好、权限入口、窄屏操作、继承文档引用及独立运行/发布配置。功能与权限规则仍以 specs 为准，实际测试和发布结果见 [验收记录](acceptance-records.md)。

## 发现与修复

| 影响 | 问题与原因 | 修复结果 |
|---|---|---|
| 高 | 同一标签页退出后，QueryClient 仍保存前一账号的数据及在途查询 | 进入会话、退出、会话失效及校验失败清空查询缓存；回归验证迟到响应不重新写入缓存 |
| 高 | 个人偏好使用显示名，中文名称经清理后可能共用 default 命名空间 | 登录用户改按服务端 ID 保存收藏、最近访问和视图；同名或改名不会串用 |
| 高 | 所有页面顶栏都标“万元”，而新领域金额使用“元” | 万元提示限定在对应经营预算页面；混合工作台不作全局声明，业务概况金额明确标元；保留各表格/图表自身单位 |
| 高 | 助手路由/强制作答提示词假定全部工具金额都是整数分，解释词典也把经营预算符号与万元口径推广到全站 | 明确经营预算分→万元、新领域元字符串和可研显式 unit 的不同口径；按领域解释符号与差异，禁止将元字符串当作分或重复换算 |
| 中 | 左上角仍为“年度预算管理 / ANNUAL LEDGER”，助手全局身份也仍称预算系统 | 统一为水利财务分析 / newfc Finance Console；补同源 SVG 站点图标；年度账册仅保留为视觉风格 |
| 中 | 经营预算占“编制、实际、分析”三个一级栏目 | 合并为一个“经营预算”，原 12 个业务叶子及其权限保持可达；项目预算仍属项目领域 |
| 中 | DEFAULT_OPEN 强制展开三组，主数据未初始化时再展开主数据，跨页继续累积 | 首页默认全部收起；深链仅展开所属分组；手动展开采用单组切换；删除外壳用于展开主数据的额外 dashboard 请求 |
| 中 | 手机顶栏固定宽度的检索框将标题挤成竖排，用户菜单超出视口 | 手机检索收为按钮进入完整检索页，用户名称收起；标题单行省略；检索页控件宽度跟随可用空间 |
| 中 | 菜单已按权限裁剪，收藏/最近访问却没有裁剪；受限组织账号仍看到模型调用页签 | 个人入口按当前权限和组织范围隐藏，保留原偏好记录；模型调用页签同时要求读取权限及全组织授权 |
| 低 | /search 误高亮首页；工作台初始化文案将经营预算准备说成整个系统的前提 | 检索保留独立页面标题且不高亮业务栏目；预算初始化说明明确其他领域可独立使用 |
| 低 | 登录页无条件显示服务器初始化命令，已上线实例仍引导普通用户初始化管理员 | 页面改为账号登录帮助；运维初始化命令保留在运行手册，真实初始化错误仍由服务端提示 |
| 低 | 继承文档索引指向未导入的 RELEASE_NOTES.md 与 archive；部分浏览器用例全局取第一个下拉框 | 索引指向本仓库 CHANGELOG 与来源记录；助手筛选补可访问名称，用例定位实际业务控件 |

旧显示名/default 命名空间中的偏好不自动迁入 ID 空间，因为无法可靠证明属于哪个账号；旧记录保留，新版本中的收藏和保存视图需重新设置。授权收窄时只隐藏该账号的失效入口，恢复授权后仍可使用 ID 空间中的原偏好。

## 独立运行检查

- 仓库使用自身 `.git`，包名为 newfc-backend/newfc-frontend；未设置 remote 是既有 OPEN-01 状态，本次未创建远程仓库。
- 代码及模板使用 newfc.service、3760、/data/newfc-data/newfc.sqlite、newfc.tangdalei.com；开发代理指向 3760，E2E 使用 3761/3762 与可丢弃数据目录。
- 实际 systemd 的工作目录与固定 Node 指向 newfc；发布前本实例 ready 返回 V60。发布结果、迁移前备份和最终 schema 见验收记录。
- 历史来源说明与继承业务口径中的 newbd/lishui 名称保留；它们不是运行依赖。本次没有读写原项目目录或访问其端口、数据库、服务。
- 验证构建仅输出至 `.e2e-dist`，正式发布仍走 `scripts/deploy.sh` 的 dist.new、备份迁移、替换和就绪检查。

## 再次排查（会话与复核身份）

- CSRF 自动刷新原先会接受另一标签页的新账号并重放旧写操作；现核对账号、权限、组织范围与改密状态，仅相同授权可刷新令牌重试一次，变化时清空会话和页面缓存，要求重新登录核对。
- 普通请求、下载和助手流绑定发起时的会话代次，切换后不返回旧数据，不以迟到 401 清除新会话；助手停止旧流输出并取消读取。
- 可研报告、财务预测版本原先用显示名比较本人提交，导致同名误判、改名漏提示。服务端增加按账号 ID 推导的布尔字段，页面据此展示管理员自审例外原因，后端自审守卫保持独立校验。
- 本次检查覆盖直接 fetch 入口、下载、鉴权初始化/改密刷新及上述复核链路。跨标签页账号变化通过下一次 CSRF 校验识别；本次不声称实现即时标签页同步。无新增迁移和依赖，schema 保持 V65。
