## 浏览器验证复现

下面命令会在仓库内的专用测试目录重建夹具，不能指向业务运行库：

```bash
(cd backend && npx tsc --outDir .e2e-dist --noEmitOnError)
(cd frontend && npm run build:e2e)
(cd frontend && E2E_BACKEND_DIST=.e2e-dist npx playwright test independent-shell navigation-expansion fullscreen assistant-dock --workers=1)
```

首次运行 Playwright 时先在 frontend 执行 `npx playwright install --with-deps chromium`。E2E 默认仅使用 3761/3762 专用端口，拒绝来源项目和正式服务端口。

## 能力边界

真实模型工具调用、流式响应和合成扫描件的 OCR/费用复核完整流程已有历史验收，未评估真实业务单据准确率。正式结论由人工形成。预测工作簿在 Excel 中编辑后导入，公式引擎仅支持约定子集；检索采用关键词/FTS。规则与制度样本应按实际业务确认后使用。

后续维护重点为更多大数据量列表的完整性、审批浏览器回归、首屏与图表加载性能，以及既有测试文件的严格类型维护。
